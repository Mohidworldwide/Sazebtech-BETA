SAZEBTECH — ENHANCED WEBSITE

GETTING STARTED
Open index.html in a browser. No build process, package install or internet connection is needed for the included assets.
For local HTTP preview: python -m http.server 8000
Then open localhost:8000 in your browser.
Deploy the contents of this folder to any static website host, keeping the assets folder and HTML pages together.
